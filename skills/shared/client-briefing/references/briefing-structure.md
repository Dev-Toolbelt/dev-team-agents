## 1. Business Data

Q&A blocks for: company or professional name, WhatsApp/phone, e-mail, city, state, address, social networks, opening hours, current or desired domain, and any other basic data given. Personal identifiers are redacted per `SKILL.md` § Personal Data. Complementary notes cover how each item serves contact, service, location, digital presence and credibility.

## 2. Services, Products or Solutions

Q&A blocks for the offering. Complementary notes, when applicable:

- Main service/product
- Secondary services
- Benefits perceived by the end customer
- Strategic suggestions for positioning and presenting each one

Organize into categories when it helps. Never add a service the client did not give.

## 3. Differentials

Q&A block for differentials. Complementary notes turn each one into commercial arguments and key messages usable in any channel:

- Differential given: [differential]
- How to communicate it: [strategic explanation]
- Suggested key messages:
  - [message 1]
  - [message 2]
  - [message 3]

## 4. Competitors and Client References

Only when the client named competitors or references: Q&A block, with complementary notes on what each one says about the client's commercial and strategic positioning.

# Segment Reference Suggestions

References and competitors in the same segment, offering or positioning. Apply the reference rule in `SKILL.md` § Content Rules (no invented names or URLs; archetype when unsure; local first when city/state is known; national or premium when it fits). For each:

```markdown
## [Reference name or archetype]

**Why it is a good reference:** [brief reason]

**What to observe:**
- Market positioning
- Language and tone of communication
- How services/products are presented
- Visual identity and brand perception
- Differentials communicated
```

## 5. Target Audience

Only when the client informed something about the audience: Q&A block, then:

### Probable Audience Profile

- **Estimated age range:**
- **Estimated income bracket:**
- **Probable location:** [from the city, state or region given]
- **Buying moment:** [when this audience looks for the offering]
- **Main desires:** [3 bullets]
- **Main pains:** [3 bullets]
- **Decision criteria:** [3 bullets]
- **Recommended tone of communication:** [sophisticated, close, popular, technical, consultative, institutional, emotional…]

The whole profile is a strategic interpretation — no official data, no specific personal information.
